Object Oriented Programming is a methodology or paradigm to design a program using classes and objects.
Key concepts :
1. Data Abstraction
2. Data Encapsulation
3. Inheritance
4. Polymorphism

Q. What are classes ?
A. Class is a user defined datatype.
    Example : 
        class Player {
            int health;
            int score;
            String name;
        }

Q. What are Objects ?
A. Object is an instance of the class.
    Example :
        Player shashwat;

Q. Why Classes ?
A. Classes enables us to apply OOP concepts stated above.
