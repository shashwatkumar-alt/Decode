constructor is a special member function that is automatically called when an object of a class is created.

Key Characteristics : 
1. Same Name: The constructor must have the exact same name as the class.
2. No Return Type: It does not return any value, so you do not specify a return type, not even void.
3. Automatic Invocation: It triggers implicitly during instantiation; you do not call it like a regular method.
4. Overloading: A class can have multiple constructors with different parameters.


Types of constructors :
1. default constructor.
2. Parameterized constructor.
3. copy constructor.
